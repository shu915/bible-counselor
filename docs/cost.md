# 費用の試算

**計測済み(2026-11-20。下の表)**。この版(LLM だけ)は、1回の相談で、OpenRouter を1回だけ呼ぶ(箇所の選択・本文・解説・結論を、まとめて書かせる)。

- 出力が長い(箇所3つの本文・解説・結論)。上限は、出力 8,000 トークン(推論を含む)。入力は、規則の長いプロンプトが大半
- 参照元(RAG 版)の実測は、1回の相談で、約 $0.03〜0.05(書き換え・選択・生成の3回。`anthropic/claude-sonnet-5.5` で、書く仕事を行った場合)。この版は、呼び出しが1回で、検索・埋め込みがない。ただし、本文も書くので、出力は増える。**同じくらいか、少し安い**と見込むが、**実測して、ここに書く**
- 回数制限(IP 5回・全体 100回/日)と、OpenRouter の月の上限($5)で、最大の費用を決める([docs/rate-limit.md](rate-limit.md))
- Upstash Redis: 回数を数えるだけ(1回の相談で数コマンド)。無料枠(1 か月 500,000 コマンド)に、十分収まる。契約の前に、公式の料金ページで確認する
- DB(Neon)・埋め込み・ベクトルは、使わない(参照元の費用は、なくなった)

## 計測(2026-11-20)

`npm run counsel [棚]` で、同じ短い入力(約40字)を、3つの棚で、1回ずつ。モデルは `anthropic/claude-sonnet-5.5`。単価は、入力 $2 / 出力 $10(100万トークンあたり。Anthropic の公開価格。OpenRouter 経由の請求は、少し違うことがある)。為替は 1 ドル 150 円で概算。

| 棚 | 入力トークン | 出力トークン | 金額 |
|---|---|---|---|
| 一般古典 | 2,496 | 2,145 | 約 $0.026(約 4 円) |
| 聖書 | 3,030 | 1,499 | 約 $0.021(約 3 円) |
| リアリズム | 3,033 | 1,915 | 約 $0.025(約 4 円) |

- 費用の大半は、出力(推論を含む)。入力の約 0.5 万トークンぶんは、プロンプト(規則)
- 入力が最大の 500 字でも、入力は 400 トークンほど増えるだけ($0.001 未満)
- **月 $5 の上限 ÷ 約 $0.025 ≒ 200 回/月**。全体の1日の上限(100回)では、約 $2.5/日 なので、月の上限は、約 2 日で尽きる。月の上限を上げる(または、全体の1日の上限を下げる)かは、運用で決める
