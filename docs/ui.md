# 画面(UI)

見た目は、Claude Design の見本(アーチ・金・明朝・昼夜の切り替え)。共通のヘッダーは入っている。棚ごとの見た目の違いは、まだ(聖書の棚の見た目が、3つの棚に共通で出ている)。
画面: [src/app/shelf-page.tsx](../src/app/shelf-page.tsx)(棚ごとのページの骨組み。`page.tsx`・`bible/page.tsx`・`realism/page.tsx` が呼ぶ)と [src/app/counsel-form.tsx](../src/app/counsel-form.tsx)(相談の本体)。棚の文言は [src/lib/shelves.ts](../src/lib/shelves.ts)。API: [src/app/api/counsel/route.ts](../src/app/api/counsel/route.ts)。

## 確認のしかた

`npm run dev` → http://localhost:3000 。AI を呼ぶので、1回 約 $0.04(開発用のキー)。
危機の画面だけなら、AI を呼ばずに見られる(「もう死にたい」と入力すると、固定の画面が出る)。

## 棚の構成(3つ)

アプリの名前は「Shu の本棚」。棚は3つで、ページが別(パスで分ける)。

| 棚 | パス | 見出し | 雰囲気 |
|---|---|---|---|
| 一般古典 | `/`(入口) | 古典に、聞いてみる。 | 静かで、あたたかい。古今東西の書物 |
| 聖書 | `/bible` | 聖書に、聞いてみる。 | 神々しい(下の「見出しの言葉」以降は、この棚の説明) |
| リアリズム | `/realism` | 兵法に、聞いてみる。 | 冷静で、乾いている。励ましの色は、使わない |

**ヘッダー(実装済み: [src/app/site-header.tsx](../src/app/site-header.tsx))**: 左に「Shu の本棚」(トップ `/` へ戻るリンク)、右に3つの棚へのリンクと昼夜の切り替え。いまの棚には下線が付く(`aria-current="page"`)。帯の色は、昼夜で変えない(紺)。スマホは2段(上: ロゴと切り替え、下: 棚の3リンク)。ロゴの「Shu」の欧文フォント(Cormorant Garamond)は、まだ置いていない。OS の Garamond・Times で代わる(機種で字形が変わる)。置くなら、Latin の字だけに削った woff2 を `src/app/fonts/` に置き、`layout.tsx` の `localFont` で `--font-cormorant` を定義する。
**棚ごとの見た目**: 棚が変わったと分かる程度に、色や空気を変える(共通の骨組みの上で)。聖書の棚の見た目が、いまの画面。

## デザインを依頼するときに伝えること

**見出しの言葉(決定済み)**: 見出し「聖書に、聞いてみる。」/ 副題「悩みも、弱音も、懺悔も。何千年も読まれてきた言葉が、そっと寄り添います。」/ その下に小さく「無料 ・ 書いた内容は保存されません」。
(「答えます」と言い切らない。夜とは限らないので、夜を前提にしない。これは聖書の棚の見出し。ほかの棚の見出しは、上の表)

**アプリの性格**: 悩み・愚痴・弱音・懺悔を打ち明けると、聖書(口語訳)の言葉を3つ引いて、それぞれに解説を添え、最後に結論を返す。
とても繊細な内容を扱うので、静かで、あたたかく、**神々しい(ホーリー)**雰囲気。信者でない人も使う(押しつけがましくしない)。説教臭くしない。

**画面の状態**(すべて、デザインが要る)

| 状態 | 内容 |
|---|---|
| 初期 | 見出し・説明・入力欄(500字まで。文字数表示)・「聖書に聞く」ボタン・注意書き |
| 待ち | 20秒ほどかかる。「探しています」の表示(光がゆっくり脈打つ、など。動きを減らす設定の人には止める) |
| 結果 | 前置き(あれば)→ 引用と解説 ×3 → 結論 → 注意書き |
| 危機 | AI を呼ばない固定の画面。相談窓口の案内(窓口名・番号は公開前に確認して入れる)。「それでも、聖書の言葉を聞いてみる」の選択肢 |
| エラー | 入力の誤り・混雑や今月の上限・失敗(固定のやさしい文) |

**結果の中身(1つの引用)**

- 見出し: 書名 章:節(例: マタイによる福音書 6:19-24)
- 引用: 「意味が通じる範囲」の節だけを見せる。その中の**核心の節は太字**。節の番号つき
- 「この段落の全文を開く(N節)」: 開くと、段落の全部の節(核心は太字)
- **引用の直下に、解説**(AI が書いたもの。引用とは、見た目で区別する)
- 引用(AI が口語訳の記憶から書いた本文)と解説は、見た目で区別できるようにする

**結果の全体**: 前置き(「それは聖書には載っていませんが、…」)→ [引用 → 解説]×3 → 結論(全体のまとめと、小さな一歩)。
結果に、「相談窓口の案内」を添えることがある(命の危険を示す入力で、「それでも続ける」を選んだとき)。

**守ること**

- 入力と結果は、保存しない・ログに出さない(画面には、「保存されません」と出す)
- 文字は、読みやすく(引用は 200〜450字ほど。長すぎると読まれない)。明朝系の聖句と、ゴシック系の解説、など、役割を分ける案
- 色の対比は、読める強さに(WCAG AA)。スマホの幅で、横スクロールしない
- 夜用(ダーク)にも対応したい(深い紺に、金の光、など)

Claude Design の「Bible RAG」(2026-11-05)。色は、生成り・紺・金、見出しと聖句は Shippori Mincho、本文は Noto Sans JP。
