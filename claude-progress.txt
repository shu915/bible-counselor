## つまずいたことのメモ(技術)

- `next/font/google` の日本語フォントは、`next dev`(Turbopack)で、「Module not found: @vercel/turbopack-next/internal/font/google/font」で落ちる(build は通る)。→ 削った woff2 を `src/app/fonts/` に置いて、`next/font/local`(済み)
- macOS の npm は、ロックから `@rolldown/binding-*` を落とす。→ 空のフォルダで `npm install --package-lock-only` して、人がロックを置く(ガードの対象)
- Tailwind の `light-dark()` は、ビルド時に、古いブラウザでも動く形に変換される(`@supports` の保険は、要らない)
- ガードは、`rm -r`、ボリュームを消す docker のコマンド、ロックや聖書のデータの書き込み、環境変数のファイルを含むコマンドを止める。迂回せず、人にお願いする。コマンドの中の文字列にも反応するので、メモの文面にも、気をつける
- zsh は、変数を単語に分けない(配列で渡す)。`&&` でつなぐと、ガードが誤検知することがある
- 検索エンジンに載せない設定(noindex)が入っている。広く公開するときに、`next.config.ts` と `layout.tsx` の両方から外す
